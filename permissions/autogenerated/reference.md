## Default Permission

Default permissions for the fingerprint plugin

#### This default permission set includes the following:

- `allow-check-device`
- `allow-get-device-info`
- `allow-capture`
- `allow-capture-frames`
- `allow-enroll`
- `allow-verify`
- `allow-identify`
